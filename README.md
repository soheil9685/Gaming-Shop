# Gaming Shop 🏪

## Overview 📋
Gaming Shop is a simple console-based C++ application that simulates a gaming store. It has two main panels: 
- **Admin Panel**: Allows the administrator to manage products and view store details.
- **Customer Panel**: Enables customers to browse products, add them to the cart, and complete purchases.

## Features 🛠️
### Admin Panel
- Login with password (`123456`)
- View store wallet balance
- Add new products (Headset, Monitor, Console)
- Remove products
- Search for products
- View all available products

### Customer Panel
- View all products
- Search for products
- Add products to the shopping cart
- Remove products from the shopping cart
- Recharge wallet balance
- Purchase items (if sufficient funds are available)

## Usage 📖
1. Run the program and choose between **Admin** or **Customer** panel.
2. If logging in as admin, enter the password (`123456`).
3. If using the customer panel, interact with the available options.
4. Follow on-screen instructions to manage or purchase products.
